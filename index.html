Manual Paso a Paso: Publicación en GitHub Pages

1. Introducción a GitHub y GitHub Pages

GitHub es una plataforma en la nube ampliamente utilizada para almacenar proyectos de software y controlar sus distintas versiones. Permite a los programadores trabajar de forma organizada y guardar sus archivos fuente de manera segura.

Por su parte, GitHub Pages es un servicio gratuito ofrecido por GitHub que permite alojar páginas web estáticas (creadas con HTML, CSS y JavaScript) directamente desde un repositorio. Es una herramienta ideal para estudiantes de análisis de sistemas, ya que permite publicar proyectos escolares en Internet sin pagar un servidor.

2. Paso 1: Crear una cuenta en GitHub

Para iniciar el proceso de publicación, se debe crear un usuario en la plataforma oficial:

  1. Abrir el navegador web e ingresar a la página oficial: github.com.
  2. Hacer clic en el botón superior derecho llamado "Sign up" (Registrarse).
  3. Escribir un correo electrónico válido, asignar una contraseña segura y elegir un nombre de usuario.
  4. Completar la prueba de seguridad y confirmar el código enviado al correo electrónico.

3. Paso 2: Crear un nuevo repositorio

Un repositorio es una carpeta digital donde guardaremos los archivos del sitio web:

  1. Al iniciar sesión, presionar el ícono con el signo de más (+) en la esquina superior derecha y seleccionar "New repository".
  2. En el campo Repository name, escribir un nombre para el proyecto (ejemplo: mi-primer-sitio).
  3. Asegurarse de mantener seleccionada la opción Public (Público).
  4. Marcar la casilla que dice "Add a README file".
  5. Hacer clic en el botón verde "Create repository" al final de la página.

4. Paso 3: Subir o crear el archivo index.html

El archivo principal del sitio web siempre debe llamarse index.html para que el servidor lo lea automáticamente:

  1. Dentro del repositorio creado, hacer clic en el botón "Add file" y seleccionar "Create new file".
  2. En la casilla de nombre del archivo, escribir exactamente: index.html (todo en minúsculas).
  3. Copiar y pegar el código HTML del sitio web en el cuadro de texto principal.
  4. Ir al final de la página y presionar el botón verde "Commit changes..." para guardar.

5. Paso 4: Configurar GitHub Pages en Settings

Una vez guardado el archivo, se debe activar la función de publicación web:

  1. En la barra de pestañas superior del repositorio, hacer clic en "Settings" (Configuración).
  2. En el menú lateral izquierdo, buscar el apartado "Pages" (ubicado en la sección Code and automation).
  3. En la sección Branch, cambiar la opción None por la rama main (o master).
  4. Hacer clic en el botón "Save" (Guardar).

6. Paso 5: Obtener el enlace del sitio publicado

Finalmente, se debe verificar que la página esté en línea:

  1. Esperar aproximadamente 2 minutos mientras GitHub procesa el código.
  2. Actualizar la página de Settings > Pages. Aparecerá un cuadro de color arriba con el mensaje: "Your site is live at...".
  3. Presionar el botón "Visit site" para abrir tu sitio web en Internet.

Lección de C# 5.0: Modificadores de Acceso y Encapsulamiento

1. El Concepto de Encapsulamiento en POO

En la Programación Orientada a Objetos (POO), el encapsulamiento es el principio de proteger los datos internos de una clase para evitar que sean modificados de manera directa o incorrecta desde fuera de ella. Permite ocultar los detalles de implementación y exponer únicamente lo necesario a través de métodos o propiedades públicas.

2. ¿Para qué sirven los Modificadores de Acceso?

Los modificadores de acceso son palabras clave utilizadas en lenguajes como C# para definir el nivel de visibilidad o alcance que tienen las variables, atributos y métodos dentro del programa. Sirven para dar seguridad al código y garantizar la integridad de los datos de la aplicación.

3. Los 4 Modificadores de Acceso Principales en C# 5.0

En la versión 5.0 del lenguaje C# contamos con los siguientes cuatro modificadores principales:

  • public: El elemento es accesible desde cualquier clase o archivo del programa. No posee restricciones.
  • private: El elemento solo es accesible dentro de la misma clase donde fue creado. Es el nivel de acceso más restringido.
  • protected: El elemento es accesible dentro de su propia clase y también en las clases hijas que hereden de ella.
  • internal: El elemento es accesible desde cualquier clase que pertenezca al mismo proyecto o archivo compilado (.exe o .dll).

4. Ejemplo Práctico Integrador en C# 5.0

A continuación se presenta un programa completo escrito en C# 5.0 que demuestra el funcionamiento del encapsulamiento mediante una clase bancaria:

using System;

namespace EjercicioIutepi
{
    // Clase que representa una Cuenta Bancaria
    public class CuentaBancaria
    {
        // 1. ATRIBUTO PRIVADO (private): Solo se lee/modifica DENTRO de esta clase.
        private double saldo;

        // 2. ATRIBUTO PROTEGIDO (protected): Accesible en esta clase y por herencia.
        protected string titular;

        // 3. ATRIBUTO INTERNO (internal): Accesible desde todo el proyecto actual.
        internal string numeroCuenta;

        // CONSTRUCTOR PÚBLICO (public)
        public CuentaBancaria(string titular, string numeroCuenta, double saldoInicial)
        {
            this.titular = titular;
            this.numeroCuenta = numeroCuenta;
            this.saldo = saldoInicial;
        }

        // MÉTODOS PÚBLICOS (public) para manipular la variable privada con seguridad
        public void Depositar(double monto)
        {
            if (monto > 0)
            {
                this.saldo += monto;
                Console.WriteLine("Depósito de $" + monto + " exitoso.");
            }
        }

        public void MostrarInformacion()
        {
            Console.WriteLine("Titular: " + this.titular);
            Console.WriteLine("Número de Cuenta: " + this.numeroCuenta);
            Console.WriteLine("Saldo Actual: $" + this.saldo);
        }
    }

    // Clase Ejecutable principal
    class Program
    {
        static void Main(string[] args)
        {
            // Creación del objeto instanciando la clase
            CuentaBancaria miCuenta = new CuentaBancaria("Fabián Cáceres", "0102-00256272", 150.0);

            // Acceso a métodos públicos
            miCuenta.MostrarInformacion();
            miCuenta.Depositar(50.0);
            miCuenta.MostrarInformacion();

            // EJEMPLO DE ERROR DE COMPILACIÓN POR ENCAPSULAMIENTO:
            // miCuenta.saldo = 1000.0; // ERROR: 'saldo' es privado y no se puede tocar desde afuera.

            Console.WriteLine("Presione una tecla para finalizar...");
            Console.ReadKey();
        }
    }
}
